3. BEAM188 Orientation — K Node

한 줄 요약: K 노드는 "단면의 높이 방향"을 정하는 점이다. 보가 어느 쪽으로 서 있는지(I형강이 세워져 있는지 눕혀져 있는지)를 ANSYS에 알려 준다. 원형 단면(csolid, ctube)은 어느 쪽으로 돌려도 같으므로 K가 필요 없다.

Setting the axes — 3 steps

  1. x축 = I → J. e,I,J,K에서 첫 번째 노드에서 두 번째 노드로.
  2. z축 = 보에서 K를 향하는 쪽. K에서 보 선에 수선을 내리고, 그 발에서 K로 가는 방향이 z. 거리는 상관없고 방향만 쓴다(K가 보에서 1이든 100이든 같다). Help 원문: “I, J와 K가 element x축과 z축을 담는 평면을 만든다.”
  3. y축 = z × x (오른손 법칙). 외우기 쉬운 형태: 화면에서 x가 오른쪽, z가 위면 y는 화면 안쪽(⊗).

Three things K changes

무엇규칙K를 보 위(+Y)에 둔 수평 보
단면 방향2장 단면 그림의 y, z = element y, z. I·CHAN·RECT의 높이(W3, H)는 z 방향높이가 세로 → 연직 하중을 강축으로 받음
sfbeam 하중 방향양(+)의 PRES: face 1 = element −z, face 2 = element −y 방향으로 누름sfbeam,all,1,pres,w = 아래로 w
결과 이름모멘트·전단력도 element 축 기준굽힘모멘트 MY = smisc,2 / 15, 전단력 SFZ = 5 / 18

Without K (default)

  • element y가 global X-Y 평면과 평행하게 자동으로 정해진다. 보가 +X 방향이면 y = +Y, z = +Z(화면 밖). 보가 global Z와 평행하면 y = global Y.
  • 그래서 X-Y 평면 프레임에서 K를 빼면 z가 화면 밖 → I·CHAN·RECT의 높이가 옆으로 누워 약축으로 휜다. W12×26이면 변위가 약 11배(= Iyy/Izz ≈ 204/17.3) 크게 나온다. 그림 ②.
  • 이때 연직 하중은 −y 방향 = face 2, 모멘트는 MZ = smisc,3 / 16.
  • ASEC 단면은 높이 대신 Iyy, Izz를 직접 넣으므로 K 없이 쓰고, 강축 I를 Izz 자리에 넣는다(secdata,A,Iyy,Iyz,Izz,Iw,J).

Writing the commands

  • 노드로 직접: K용 노드를 따로 만들고 요소의 세 번째 노드로 준다. 예) n,100,0,10 → e,1,2,100. K용 노드는 해석에 안 들어가므로 구속할 필요 없음(연습기는 그림에서도 숨김).
  • 키포인트 + LMESH: 방향용 키포인트를 만들고 latt,,,,,KB — 쉼표 5개(LATT, MAT, REAL, TYPE, --, KB). 그 뒤 lmesh가 K 노드를 자동으로 만든다. (1013.txt의 latt,,,,3은 쉼표가 4개라 무시됨)
  • KB 하나로 보와 기둥 둘 다: 수업 예제 k,4,0,109는 보(선 1)에서 보면 위쪽, 기둥(선 2)에서 보면 왼쪽(−X)이다 → 두 부재 모두 높이가 프레임 평면 안에 선다.
  • K가 보 선 위(연장선 포함)에 있으면 방향을 정할 수 없어 오류.

  • 변위가 손계산보다 10배쯤 크면 → 약축으로 휘고 있는 것. K 위치부터 의심.

4. SFBEAM (Beam Surface Loads)

sfbeam,Elem,LKEY,PRES,VALI,VALJ,VAL2I,VAL2J,IOFFST,JOFFST,LENRAT

  • Elem: 요소 번호 또는 all(선택된 전체)
  • LKEY(BEAM188): 1 = element −z 방향(I-J 면), 2 = element −y 방향, 3 = 접선(+x), 4 = I 끝, 5 = J 끝
  • VALI, VALJ: I절점, J절점 값. VALJ 생략 → VALI와 같음(등분포). 삼각/선형 분포하중 = VALI≠VALJ
  • IOFFST, JOFFST: 요소 끝에서 하중 시작/끝 위치 오프셋, LENRAT=1이면 비율(0~1). 오프셋은 KEYOPT(3)=3(3차)일 때만 사용 가능. JOFFST=-1이면 IOFFST 위치에 VALI 집중하중
  • 음수 값 = 반대 방향
  • ⚠ 옛 요소 BEAM3는 face 1이 −Y 방향 → 옛 스크립트의 sfbeam,…,1,…(BEAM3)은 BEAM188에서는 보통 face 2(K 노드 없을 때)

Triangular distributed load

  1. 하중이 꺾이는 점(최댓값), 지점, 결과를 볼 점에 노드가 오도록 선을 나눈다.
  2. 구간마다 선형이므로, 요소 하나하나에 VALI, VALJ를 그 위치의 하중값으로 준다. 요소가 많으면 *do 반복문 사용:
! 가운데(a)에서 최대 wmax, 양 끝(0, L)에서 0인 대칭 삼각하중 : w(x) = wmax*(1-|x-a|/a)
wmax=25000                          ! 파라미터 wmax = 25000
a=3.75                              ! 파라미터 a = 3.75 — 꼭짓점 위치 (= L/2)
*get,ne,elem,,count                 ! ne = 선택된 요소 개수
*do,i,1,ne                          ! 반복 시작: i = 1 ~ ne
  xi=nx(nelem(i,1))                 ! 파라미터 xi = nx(nelem(i,1)) — 요소 i의 I 노드 x좌표
  xj=nx(nelem(i,2))                 ! 파라미터 xj = nx(nelem(i,2)) — J 노드 x좌표
  sfbeam,i,1,pres,wmax*(1-abs(xi-a)/a),wmax*(1-abs(xj-a)/a)  ! 요소 i, face 1 = element −z 방향에 분포하중 wmax*(1-abs(xi-a)/a) → wmax*(1-abs(xj-a)/a) (선형 분포)
*enddo                              ! 반복 끝

요소를 12개(앞 6개 + 뒤 6개)로 균등하게 나눈 경우, 좌표 없이 요소 번호만으로 쓰는 간단한 형태. 최댓값 25000이 보 가운데에 오고 양 끝은 0:

! 요소 1~12 균등 분할, 가운데(요소 6·7 경계)에서 최대 25000인 삼각하중
*do,i,1,6                           ! 왼쪽 절반: 반복 i = 1 ~ 6
sfbeam,i,,pres,25000/6*(i-1),25000/6*i  ! 요소 i, LKEY 생략 = face 1(−z 방향). 하중 0 → 25000 으로 증가 (요소마다 25000/6씩)
*enddo                              ! 반복 끝

*do,i,7,12                          ! 오른쪽 절반: 반복 i = 7 ~ 12
sfbeam,i,,pres,25000-25000/6*(i-7),25000-25000/6*(i-6)  ! 요소 i, face 1. 하중 25000 → 0 으로 감소
*enddo                              ! 반복 끝
  • 요소 번호가 1~12로 왼쪽에서 오른쪽 순서일 때만 맞다(선을 12등분해 lmesh/esize로 메쉬하면 보통 그렇다). 확인은 elist.
  • LKEY를 비워 두면 face 1이다. K 노드 없이 element y = global Y인 보는 face 2이므로 sfbeam,i,2,pres,…로 쓴다.
  • 왼쪽 절반은 i=1일 때 0 → 25000/6, 마지막 i=6에서 25000. 오른쪽 절반은 i=7에서 25000부터 시작해 i=12에서 0으로 끝난다(연속).

⚠ APDL에는 <= 같은 참/거짓 비교식이 없다. (A<B)는 둘 중 작은 값, (A>B)는 큰 값을 돌려준다. 꼭짓점이 가운데가 아니면 *if,xi,le,a,then … *else … *endif로 나눈다.
face 번호는 K 노드를 위(+Y)에 둔 경우 1, K 노드 없이 element y = global Y이면 2.

손으로 쓰기 편하려면 노드를 하중 꺾이는 점·지점에만 두고(요소 3~4개), KEYOPT(3)=3(3차)으로 해도 정확도가 충분하다. 결과 비교해 보고 쓸 것.

  • sfbeam,all,1,…: face 1 = element −z 방향 = 보에서는 −Y(아래). all은 그 순간 선택된 요소만 뜻하므로, 기둥을 메쉬하기 전에 쓰면 보에만 하중이 걸린다.
  • secoff,user,0,12.22: 단면 1의 오프셋은 메쉬 뒤에 바꿔도 단면 1을 쓰는 모든 요소(보·기둥)에 적용된다. /ESHAPE 그림에서 보가 선 아래로 매달리는 모양이 된다. 주석 처리된 -6.11+0.38은 다른 위치를 시험해 본 값.
