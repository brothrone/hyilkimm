Example 1.1 — 폭이 줄어드는 봉

  • 알루미늄 E = 10.4×10⁶ lb/in², w₁ = 2 in, w₂ = 1 in, 두께 t = 0.125 in, L = 10 in, P = 1000 lb. 위 끝 고정.
  • 요소 4개(각 2.5 in)로 나누고, 각 요소의 단면적 = 양 끝 단면적의 평균(A(y) = 0.25 − 0.0125y). → 0.234375, 0.203125, 0.171875, 0.140625 in².
  • 단면이 다른 구간마다 sectype을 따로 만들고 *do 안에서 secn,i로 바꿔 가며 요소 생성. 기출 2021-1(테이퍼 판)과 같은 방식이다.

Problem 3.3 — 60° 두 부재

  • 알루미늄 E = 10.0×10⁶ lb/in², A = 2.3 in². A의 처짐, 부재 응력, 반력.
  • A의 좌표 = (3 ft·cos60°, 3 ft·sin60°). APDL의 sin·cos는 라디안이 기본이라 각도에 π/180을 곱했다(또는 *afun,deg를 먼저).
  • 손계산: 대칭이므로 각 부재 압축력 = 200 / (2 sin60°) = 115.5 lb.
