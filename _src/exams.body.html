Problem 1 — 2단 원형 축의 비틀림 (BEAM188, CSOLID)

모델링

  • 단면: sectype,,beam,csolid. secdata에는 반지름을 넣는다 (지름이 아님).
  • G가 따로 주어졌다. mp,prxy를 ν = E/(2G) − 1로 넣으면 ANSYS가 계산하는 G가 주어진 값과 정확히 같아진다. 그래서 AB는 ν = 0.3333, BC는 ν = 0.3이다. mp,gxy로 G를 직접 넣어도 된다.
  • 토크 200 lb·ft = 2400 lb·in. 축이 global X 방향이므로 f,node,mx, 결과는 ROTX로 읽는다.
/prep7
/title,2016-1 torsion shaft
et,1,beam188,,,3
sectype,1,beam,csolid
secdata,1.5/2                      ! 반지름 0.75 in
sectype,2,beam,csolid
secdata,1/2                        ! 반지름 0.5 in
mp,ex,1,10.4e6
mp,prxy,1,10.4/(2*3.9)-1           ! → G = 3.9e6
mp,ex,2,10.4e6
mp,prxy,2,10.4/(2*4.0)-1           ! → G = 4.0e6
n,1,0                              ! A
n,2,2.5*12                         ! D
n,3,3.5*12                         ! B
n,4,5.5*12                         ! C
mat,1 $ secnum,1
e,1,2 $ e,2,3
mat,2 $ secnum,2
e,3,4
d,1,all
d,4,all
f,2,mx,200*12
finish
/solu
solve
finish
/post1
prnsol,rot,comp                    ! (a) 노드 2(D), 3(B)의 ROTX
prrsol                             ! (b) 노드 1, 4의 MX
결과검증값 (해석해)
(a) D점 비틀림각0.0302 rad (1.73°)
(a) B점 비틀림각0.0274 rad (1.57°)
(b) A점 반력 토크1951 lb·in (162.6 lb·ft)
(b) C점 반력 토크449 lb·in (37.4 lb·ft)

해석해: 각 구간의 비틀림 강성은 k = GJ/L이다. J = πd⁴/32이고, AD 구간 k = 64,611, DB 구간 161,529, BC 구간 16,362 lb·in/rad다. D점에서 왼쪽(AD)과 오른쪽(DB와 BC를 직렬)이 병렬로 토크를 나눠 받는다. 반력 합은 1951 + 449 = 2400 lb·in으로 가한 토크와 같다. CSOLID 단면은 원을 셀로 나눠 근사하므로 ANSYS 값이 해석해와 조금 다를 수 있다. 그때는 원주 분할 수 N을 늘린다(secdata,0.75,16).

Problem 2 — 양단 고정보 + 가운데 스프링, 최소 k (BEAM188 + LINK180)

모델링

  • A와 I만 주어졌으므로 sectype,,beam,asec를 쓴다. 순서는 A, Iyy, Iyz, Izz, Iw, J다. K 노드가 없으면 하중 방향이 element −y이므로 Izz = 2e-4로 넣고, 하중은 face 2로 준다. J는 주어지지 않았지만 0이면 강성행렬이 특이해지므로 아무 양수나 넣는다(결과와 무관).
  • 스프링: LINK180, sectype,,link, 단면적 A = kL/E.
  • 최소 k는 중첩법으로 구한다: 스프링 없이 δ₀ = wL⁴/384EI, 가운데 단위하중 유연도 f = L³/192EI, k = (δ₀/0.15 − 1)/f.
/prep7
/title,2016-2 beam + spring
et,1,beam188,,,3
sectype,1,beam,asec
secdata,1e-2,2e-4,0,2e-4,0,1e-4    ! A, Iyy, Iyz, Izz, Iw, J(임의 양수)
mp,ex,1,210e9
mp,prxy,1,0.3
et,2,link180
kmin=7333.4                        ! 중첩법으로 구한 값 (아래)
sectype,2,link
secdata,kmin*10/210e9              ! A = kL/E = 3.49e-7 m²
*do,i,1,21                         ! 2 m 간격, 노드 11 = P (x = 20 m)
  n,i,(i-1)*2
*enddo
n,22,20,-10                        ! 스프링 바닥
type,1 $ mat,1 $ secnum,1
*do,i,1,20
  e,i,i+1
*enddo
type,2 $ mat,1 $ secnum,2
e,11,22
d,1,all
d,21,all
d,22,all
esel,s,type,,1                     ! 보 요소만 선택
sfbeam,all,2,pres,1000             ! face 2 = element −y = 아래, 1 kN/m
allsel
finish
/solu
solve
finish
/post1
prnsol,u,y                         ! 노드 11 UY ≈ −0.150 m
결과검증값
스프링 없을 때 P점 변위 δ₀wL⁴/384EI = 0.1587 m (> 0.15라서 스프링이 필요)
P점 유연도 fL³/192EI = 7.94×10⁻⁶ m/N
최소 k(0.1587/0.15 − 1)/f = 7.33×10³ N/m
LINK180 단면적A = kL/E = 7333×10/210×10⁹ = 3.49×10⁻⁷ m²

옛 풀이(중간고사 16년.txt)의 LINK1 실상수 r,2,0.0000004(4×10⁻⁷)는 이 값을 반올림한 것이다. 최신 방식에서는 sectype,,link + secdata로 쓴다.

모델링
