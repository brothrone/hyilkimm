Class Notation

수업 txt 파일(9/30~10/21, 1001·1006·1013, 중간고사 대비·풀이)에는 정식 이름과 다르게 쓴 표기가 몇 가지 있다. 모두 같은 일을 하므로 헷갈릴 때 아래 설명을 보면 된다.

  • 포아송비 — nuxy와 prxy. 수업에서는 mp,nuxy,1,0.3으로 쓴다. 정식 이름은 prxy이지만 등방성 재료에서는 두 이름이 같은 값을 뜻한다. 둘 중 하나만 입력하면 된다.
  • 반력 출력 — prrfor와 prrsol. 수업은 prrfor를 쓰지만 ANSYS Help에는 prrfor가 "FORCE 명령과 함께 쓰는" 옛 명령으로 적혀 있다. 일반적인 반력 출력은 prrsol이고, 실습 중 prrfor가 실행되지 않은 것도 이 때문으로 보인다. 안 될 때는 prrsol로 바꿔 쓴다.
  • 변위·회전 출력 — prnsol,u,sum, prnsol,rot,sum. 이름에 sum이 붙어도 UX UY UZ USUM이 한 번에 모두 나온다. 한 성분만 보고 싶으면 prnsol,u,y처럼 쓴다.
  • 요소 정의 줄임 — et,1,beam188,,,3. 쉼표가 비어 있는 칸은 KEYOPT(1), KEYOPT(2)이고 세 번째 칸이 KEYOPT(3)이다. 그래서 et,1,beam188을 쓰고 keyopt,1,3,3을 따로 쓴 것과 같다. 3은 "3차 형상함수"를 뜻한다.
  • 요소 표 — etable. 앞의 이름(예: axforce, axstress)은 마음대로 지어도 된다. 만든 뒤에는 pretab으로 목록을, pletab으로 그림을 본다. 축력은 smisc,1, 축응력은 ls,1이다.
  • 명령 줄임. 수업에서는 pcir(= PCIRC), rect(= RECTNG), wpoff(= WPOFFS), secn(= SECNUM), secoff(= SECOFFSET)처럼 줄여 쓴다. ANSYS는 명령의 앞 네 글자까지만 구별하므로 이렇게 써도 알아듣는다.
  • 요소 분할 — esize. esize,0.2처럼 첫 칸에 쓰면 요소 길이이고, esize,,4처럼 둘째 칸에 쓰면 선 하나를 4등분하라는 뜻(NDIV)이다.
  • 처리기 바꾸는 순서. 전처리기에서 해석기로, 해석기에서 후처리기로 넘어갈 때마다 먼저 finish를 하고 /solu, solve, finish, /post1 순서로 간다.

⚠ LATT 쉼표 개수. 1013.txt의 latt,,,,3은 쉼표가 4개라서 3이 비어 있는 4번째 칸에 들어가 무시된다. 방향 키포인트(KB)는 5번째 칸이므로 최신 수업 스크립트처럼 쉼표를 5개 쓰고 그 뒤에 키포인트 번호를 적는다(latt,,,,,4 형태). 연습기는 4개로 쓰면 NOTE로 알려 준다.

0. Basic Template

어떤 문제든 풀이는 아래 순서를 따른다. 각 단계에서 쓰는 명령 이름을 적어 두었다.

  1. 전처리기 진입과 제목. /prep7로 모델링을 시작하고 /title로 문제 이름을 붙인다(제목은 생략해도 된다).
  2. 요소 · 단면 · 재료 정의.
    • et로 요소 종류를 정한다. 보는 BEAM188, 트러스·봉은 LINK180, 2차원 면은 PLANE182이다. 보에서는 정확도를 위해 KEYOPT(3)=3(3차)을 함께 준다.
    • sectype과 secdata로 단면 종류와 치수를 넣는다. 치수 순서는 단면 종류마다 다르니 2장을 본다.
    • mp,ex로 탄성계수, mp,nuxy로 포아송비를 넣는다. 재료가 여러 개면 번호를 달리해서 각각 입력한다.
  3. 형상 만들기. 두 가지 방법이 있다. 위에서 아래로 가는 방법은 k(키포인트) → l(선) → esize → lmesh이고, 아래에서 위로 가는 방법은 n(노드) → e(요소)이다.
  4. 경계조건과 하중. 구속은 d, 집중하중은 f, 보의 분포하중은 sfbeam으로 준다.
  5. 해석. finish로 전처리기를 나오고, /solu에 들어가 solve를 실행한 뒤 다시 finish한다.
  6. 후처리. /post1에 들어가 set,last로 결과를 읽는다. 변위와 회전은 prnsol,u,sum, prnsol,rot,sum으로, 반력은 prrsol로 본다(수업의 prrfor는 안 될 수 있음). 반력의 합이 하중과 같은지 보면 평형 검증이 된다.
  • 단위는 ANSYS가 정하지 않는다 → 입력을 한 단위계로 통일 (in-lb-psi / m-N-Pa).
  • 기본 attribute = type,1 mat,1 real,1 secn,1. 여러 개면 메쉬·요소 생성 전에 바꿔 준다.
  • 확인용: /pnum,node,1 · /pnum,elem,1 로 노드·요소 번호 켜고 nplot / eplot 으로 그린다. 기호는 /psymb(좌표계 cs, 노드 좌표계 ndir, 요소 좌표계 esys)와 /pbc,all,,1(구속·하중). /eshape,1 + eplot 은 보를 단면 모양으로 보기. 수업 파일 1013.txt 처럼 /pnum node 1 로 쉼표 없이 쓰면 연습기는 오류로 보니 쉼표로 쓸 것 (/pnum,node,1)

2. Sections (SECTYPE / SECDATA)

단면은 네 가지 명령이 짝을 이룬다. 각각이 하는 일은 이렇다.

  • sectype,SECID,Type,Subtype — 단면 번호(SECID)를 정하고 종류를 알려 준다. Type은 보면 beam, 봉이면 link이다. 보일 때만 Subtype(rect, csolid, i, chan 등)을 적는다.
  • secdata,값1,값2,... — 바로 앞 sectype에 대한 치수를 순서대로 넣는다. 순서는 Subtype마다 다르므로 아래 표에서 확인한다. 항상 sectype 바로 다음 줄에 쓴다.
  • secoff,Location,OFFSETY,OFFSETZ — 보 노드가 단면의 어디에 놓일지 정한다(아래 SECOFFSET 절).
  • secn,SECID — 이후에 만드는 요소가 몇 번 단면을 쓸지 정한다. 단면을 여러 개 만들었다면 요소를 만들기 전에 바꿔 준다.

3. BEAM188 Orientation — K Node

한 줄 요약: K 노드는 "단면의 높이 방향"을 정하는 점이다. 보가 어느 쪽으로 서 있는지(I형강이 세워져 있는지 눕혀져 있는지)를 ANSYS에 알려 준다. 원형 단면(csolid, ctube)은 어느 쪽으로 돌려도 같으므로 K가 필요 없다.

Setting the axes — 3 steps

  1. x축 = I → J. e,I,J,K에서 첫 번째 노드에서 두 번째 노드로.
  2. z축 = 보에서 K를 향하는 쪽. K에서 보 선에 수선을 내리고, 그 발에서 K로 가는 방향이 z. 거리는 상관없고 방향만 쓴다(K가 보에서 1이든 100이든 같다). Help 원문: “I, J와 K가 element x축과 z축을 담는 평면을 만든다.”
  3. y축 = z × x (오른손 법칙). 외우기 쉬운 형태: 화면에서 x가 오른쪽, z가 위면 y는 화면 안쪽(⊗).

Three things K changes

무엇규칙K를 보 위(+Y)에 둔 수평 보
단면 방향2장 단면 그림의 y, z = element y, z. I·CHAN·RECT의 높이(W3, H)는 z 방향높이가 세로 → 연직 하중을 강축으로 받음
sfbeam 하중 방향양(+)의 PRES: face 1 = element −z, face 2 = element −y 방향으로 누름sfbeam,all,1,pres,w = 아래로 w
결과 이름모멘트·전단력도 element 축 기준굽힘모멘트 MY = smisc,2 / 15, 전단력 SFZ = 5 / 18

Without K (default)

  • element y가 global X-Y 평면과 평행하게 자동으로 정해진다. 보가 +X 방향이면 y = +Y, z = +Z(화면 밖). 보가 global Z와 평행하면 y = global Y.
  • 그래서 X-Y 평면 프레임에서 K를 빼면 z가 화면 밖 → I·CHAN·RECT의 높이가 옆으로 누워 약축으로 휜다. W12×26이면 변위가 약 11배(= Iyy/Izz ≈ 204/17.3) 크게 나온다. 그림 ②.
  • 이때 연직 하중은 −y 방향 = face 2, 모멘트는 MZ = smisc,3 / 16.
  • ASEC 단면은 높이 대신 Iyy, Izz를 직접 넣으므로 K 없이 쓰고, 강축 I를 Izz 자리에 넣는다(secdata,A,Iyy,Iyz,Izz,Iw,J).

4. SFBEAM (Beam Surface Loads)

sfbeam,Elem,LKEY,PRES,VALI,VALJ,VAL2I,VAL2J,IOFFST,JOFFST,LENRAT

  • Elem: 요소 번호 또는 all(선택된 전체)
  • LKEY(BEAM188): 1 = element −z 방향(I-J 면), 2 = element −y 방향, 3 = 접선(+x), 4 = I 끝, 5 = J 끝
  • VALI, VALJ: I절점, J절점 값. VALJ 생략 → VALI와 같음(등분포). 삼각/선형 분포하중 = VALI≠VALJ
  • IOFFST, JOFFST: 요소 끝에서 하중 시작/끝 위치 오프셋, LENRAT=1이면 비율(0~1). 오프셋은 KEYOPT(3)=3(3차)일 때만 사용 가능. JOFFST=-1이면 IOFFST 위치에 VALI 집중하중
  • 음수 값 = 반대 방향
  • ⚠ 옛 요소 BEAM3는 face 1이 −Y 방향 → 옛 스크립트의 sfbeam,…,1,…(BEAM3)은 BEAM188에서는 보통 face 2(K 노드 없을 때)

Triangular distributed load

  1. 하중이 꺾이는 점(최댓값), 지점, 결과를 볼 점에 노드가 오도록 선을 나눈다.
  2. 구간마다 선형이므로, 요소 하나하나에 VALI, VALJ를 그 위치의 하중값으로 준다. 요소가 많으면 *do 반복문을 쓴다. 아래는 그 풀이 방법이다.

일반형: 꼭짓점이 a인 삼각하중을 요소별로 계산하기. 가운데(위치 a)에서 최대 wmax이고 양 끝(0과 L)에서 0인 대칭 삼각하중은 위치 x에서의 하중이 wmax × (1 − |x − a| / a)이다. 이 식을 요소의 양 끝 좌표에 각각 넣으면 VALI와 VALJ가 나온다. 반복문의 동작은 이렇다.

  1. 파라미터로 wmax(예: 25000)와 꼭짓점 위치 a(= L/2, 예: 3.75)를 정해 둔다.
  2. *get,ne,elem,,count로 선택된 요소의 개수를 ne에 담는다.
  3. *do,i,1,ne로 요소를 하나씩 돌면서, nx(nelem(i,1))로 요소 i의 I 노드 x좌표(xi)를, nx(nelem(i,2))로 J 노드 x좌표(xj)를 구한다.
  4. 요소 i에 sfbeam,i,1,pres 뒤에 VALI = wmax×(1−abs(xi−a)/a), VALJ = wmax×(1−abs(xj−a)/a)를 적어 face 1(−z 방향) 하중을 준다.
  5. *enddo로 반복을 닫는다.

  • 선 메쉬 — lmesh,all. 선을 LINK나 BEAM 요소로 나눈다.
  • 면 메쉬 — amesh,all. 면을 PLANE 요소로 나눈다.

트러스(LINK)는 선 하나 = 요소 하나 (esize,,1). 중간에 노드가 생기면 핀 절점이 생겨 불안정해진다.

  • 반력 출력: prrsol,Lab은 구속된 노드의 반력을 목록으로 출력한다. 마지막 TOTAL 줄이 반력의 합이므로, 이 값과 하중의 합이 크기가 같고 부호가 반대이면 평형이 맞은 것이다. Help에는 prrfor가 "FORCE 명령과 함께 쓰는" 명령으로 적혀 있어서 일반 해석에서는 prrsol을 쓴다.
  • 토크 부호: 오른손 법칙을 쓴다. 엄지를 +축(축 방향, 예: A에서 C로 가는 +X)에 두고 손가락이 감기는 방향이 +MX이다. 그림의 화살표가 그 방향이면 양수, 반대이면 음수로 넣는다. 부호가 달라도 크기는 같고 결과 부호만 전부 뒤집힌다.
  • 반력의 부호: 반력은 하중과 반대 방향으로 나와 하중이 +이면 반력은 −이다. 모든 구속 노드의 반력을 더하면 −하중이 된다.

12. Element KEYOPT (ANSYS Help)

KEYOPT는 요소의 동작 옵션이다. et,1,beam188,KOP1,KOP2,KOP3처럼 et에서 앞에서부터 순서대로 칸을 채우거나 keyopt,1,번호,값으로 따로 준다. 아래 값은 ANSYS Help(v261)의 BEAM188, LINK180 페이지를 직접 읽고 옮긴 것이다. 시험에서는 BEAM188의 KEYOPT(3)만 바꾸고 나머지는 기본값을 쓴다.

BEAM188

KEYOPT값의미
(1) 뒴 자유도0 (기본) / 1 / 20은 절점당 6 자유도로 뒴(warping)을 무시한다. 1은 7번째 자유도로 뒴을 넣고 바이모멘트·바이곡률을 출력한다. 2는 1과 같고 해석 전에 자동 점검을 추가한다. 얇은 벽 단면의 비틀림에서만 쓴다.
(2) 단면 크기 변화0 (기본) / 1대변형(NLGEOM,ON)일 때만 의미가 있다. 0은 축 방향으로 늘어나면 단면 크기도 따라 바뀐다. 1은 단면을 강체로 본다(고전 보 이론).
(3) 길이 방향 형상함수0 (기본) / 2 / 30은 선형, 2는 2차, 3은 3차이다. 3차를 쓰면 요소를 적게 나눠도 보 이론의 해와 거의 일치한다. 분포하중이나 굽힘 문제에서는 3을 준다. 3일 때만 sfbeam의 오프셋(IOFFST, JOFFST)을 쓸 수 있다.
(4) 전단응력 출력0 (기본) / 1 / 20은 비틀림에 의한 전단응력만, 1은 굽힘에 의한 횡전단응력만, 2는 둘을 합친 전단응력을 출력한다.
(5) 변형 공간0 (기본) / 10은 3차원 공간, 1은 XY 평면 안에서만 변형한다. 1이면 face 2(−y 방향) 하중은 쓸 수 없다.
(6) 단면력 출력 위치0 (기본) / 1 / 2 / 30은 길이 방향 적분점에서 출력한다. 1은 0에 현재 단면적을 더하고, 2는 1에 요소 기준 방향(X, Y, Z)을 더한다. 3은 요소 절점으로 외삽한 값을 출력한다(outpr,esol일 때).
(7) 적분점 출력0 (기본) / 1 / 2ASEC 단면에서는 쓸 수 없다. 1은 최대·최소 응력과 변형률, 2는 1에 각 단면 점의 값을 더해 출력한다.
(9) 외삽 절점 출력0 (기본) / 1 / 2 / 3ASEC 단면에서는 쓸 수 없다. 1은 최대·최소 값, 2는 1에 단면 바깥 경계의 값, 3은 1에 모든 단면 절점의 값을 더해 출력한다.
(11) 단면 성질 계산0 (기본) / 10은 허용되면 미리 적분된 값을 자동으로 쓴다. 1은 단면을 수치 적분한다.
(12) 테이퍼 단면0 (기본) / 10은 가우스 점마다 성질을 계산해 더 정확하지만 느리다. 1은 도심에서만 계산해 근사적이지만 빠르다.
(15) 결과 파일 형식0 (기본) / 10은 단면 모서리 절점에서 평균한 결과이다. 1은 평균하지 않은 적분점 결과로 파일이 커진다.
  • 쉼표 칸 세기가 중요하다. et,1,beam188,,,3은 KEYOPT(1), KEYOPT(2)를 비우고 KEYOPT(3)에 3을 넣은 것이다.
  • BEAM188은 단면을 sectype과 secdata로 따로 준다. KEYOPT에는 단면 정보가 들어가지 않는다.
  • 하중 면 번호(sfbeam의 LKEY): face 1은 −z 방향 수직, face 2는 −y 방향 수직, face 3은 +x 방향 접선, face 4는 I 끝 축방향(+x), face 5는 J 끝 축방향(−x)이다. 양(+)의 압력은 요소를 향해 누르고, 음수면 반대 방향이다. 옆 방향 압력은 단위 길이당 힘이고 끝 압력은 힘이다.
  • ETABLE 번호(I 끝 / J 끝): 축력 smisc 1 / 14, 모멘트 MY 2 / 15, MZ 3 / 16, 비틀림 TQ 4 / 17, 전단력 SFz 5 / 18, SFy 6 / 19, 축응력 SDIR 31 / 36이다. 굽힘응력은 SByT(+Y 쪽) 32 / 37, SByB(−Y 쪽) 33 / 38, SBzT(+Z 쪽) 34 / 39, SBzB(−Z 쪽) 35 / 40이다. 단면적은 nmisc 29이다.
