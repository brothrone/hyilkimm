ANSYS APDL 중간고사 참고자료 (시험장용)

수업 스크립트 + 강의자료 + ANSYS Help(Mechanical APDL Command/Element Reference) 정리. 모든 스크립트는 최신 요소(LINK180 / BEAM188 / PLANE182) 기준. ! 뒤는 주석.

0. 기본 틀 (모든 문제 공통)

/prep7
/title,문제이름
! 1) 요소 · 단면 · 재료
et,1,beam188,,,3          ! 또는 link180 / plane182
sectype,1,beam,i          ! 단면 형태
secdata,...               ! 단면 치수
mp,ex,1,30e6
mp,prxy,1,0.3
! 2) 형상: (top-down) k → l → esize → lmesh   또는   (bottom-up) n → e
! 3) 경계조건 · 하중  (d / f / sfbeam)
finish
/solu
solve
finish
/post1
set,last
prnsol,u,comp             ! 절점 변위 (X, Y, Z, SUM 한 번에)
prnsol,rot,comp           ! 회전
prrsol                    ! 반력  (= prrfor)
  • 단위는 ANSYS가 정하지 않는다 → 입력을 한 단위계로 통일 (in-lb-psi / m-N-Pa).
  • 기본 attribute = type,1 mat,1 real,1 secnum,1. 여러 개면 메쉬·요소 생성 전에 바꿔 준다.
  • 확인용: /pnum,node,1 /pnum,elem,1 /psymb,cs,1 /pbc,all,,1 nplot eplot /eshape,1(단면 모양 보기) slist(단면 성질 목록)

1. 요소 요약

요소 노드 자유도 단면 입력 주요 KEYOPT 옛 요소
LINK180 (3D 봉/트러스) I, J UX UY UZ sectype,1,link + secdata,A — LINK1(2D), LINK8(3D): r,1,A
BEAM188 (3D 보) I, J, (K 방향노드) UX UY UZ ROTX ROTY ROTZ (+warping) sectype,1,beam,종류 + secdata KEYOPT(3): 0 선형, 2 2차, 3 3차 → et,1,beam188,,,3 BEAM3(2D): r,1,A,I,h
PLANE182 (2D 4절점) I J K L UX UY 두께: KEYOPT(3)=3일 때 r,1,THK KEYOPT(3): 0 평면응력, 1 축대칭, 2 평면변형, 3 두께입력 평면응력 PLANE42
PLANE183 (2D 8절점) 8 UX UY 같음 같음 PLANE82
COMBIN14 (스프링) I, J KEYOPT(2)=1~3 → 1D UX/UY/UZ, 4~6 → 비틀림 ROTX/Y/Z r,1,k KEYOPT(2) —

옛 요소 LINK1·LINK8·BEAM3은 ANSYS 13.0(2010)부터 문서에서 빠진 요소(BEAM3은 10년 넘게 미지원), PLANE42는 archive. 족보 16~19년 풀이는 이 요소들을 쓰므로 LINK180/BEAM188/PLANE182로 바꿔 쓸 것. BEAM188은 real constant(r)를 무시하므로 반드시 sectype/secdata.

시험 지시가 "LINK180으로 스프링 모델링"이면 k = EA/L → secdata,A 에 A = k·L/E.

2. 단면 (SECTYPE / SECDATA)

sectype,SECID,Type,Subtype      ! Type = beam / link
secdata,VAL1,VAL2,...
secoffs,Location,OFFSETY,OFFSETZ   ! (보) 노드를 단면의 어디에 둘지
secnum,SECID                       ! 이후 생성 요소의 단면 번호
Subtype SECDATA 순서 예
link A secdata,8
rect B(폭), H(높이), Nb, Nh(셀 수) secdata,2,4
csolid R (반지름!), N(원주 분할, 기본 8), T(반경 분할, 기본 2) secdata,1.5/2
ctube Ri, Ro
i W1(위 플랜지 폭), W2(아래 플랜지 폭), W3(전체 높이), t1, t2(플랜지 두께), t3(웹 두께) W12×26: secdata,6.49,6.49,12.22,0.380,0.380,0.230
chan W1, W2(플랜지 폭), W3(전체 높이), t1, t2(플랜지 두께), t3(웹 두께) C9×20: secdata,2.648,2.648,9,0.413,0.413,0.448
hrec (사각 중공) W1, W2, t1, t2, t3, t4 secdata,6,6,0.25,0.25,0.25,0.25
asec (임의) A, Iyy, Iyz, Izz, Iw, J, CGy, CGz, SHy, SHz, TKz, TKy secdata,7.65,17.3,,204,,0.3
  • I / CHAN 단면의 높이(W3)는 단면 z방향 → 강축 = Iyy (slist로 확인: W12×26 → Iyy≈201.8, Izz≈17.3).
  • ASEC는 Iyy·Izz를 직접 넣기 때문에 하중 방향과 맞춰야 함: 하중이 element −y 방향이면 강축 I를 Izz에, −z 방향이면 Iyy에.
  • 단위 환산: 강재표 mm → m. A [mm²]×1e-6, I [10⁶ mm⁴]×1e-6 → m⁴ (예: W310×52 Ix=119×10⁶ mm⁴ = 119e-6 m⁴).

SECOFFSET (보 단면에서 노드 위치)

secoffset,Location,OFFSETY,OFFSETZ,CG-Y,CG-Z,SH-Y,SH-Z — 가장 최근 sectype 단면에 적용 → sectype / secdata 바로 다음에 쓴다. (secoffs로 줄여 써도 됨) | Location | 노드 위치 | |---|---| | CENT | 도심 (기본값) | | SHRC | 전단중심 | | ORIGIN | 단면 원점 (I/CHAN 그림의 아래 왼쪽 등) | | USER | OFFSETY, OFFSETZ로 지정한 점 (USER일 때만 이 두 값이 쓰임) |

단면 형태마다 쓸 수 없는 Location이 있을 수 있다. ASEC는 secplot으로 그릴 수 없고 응력도 안 나온다.

C형강은 전단중심 ≠ 도심 → 도심을 지나는 하중은 비틀림을 일으킨다. 두 단면(W와 C)을 이어 붙일 때 같은 기준점(예: 위 플랜지 면, 웹 중심)에 노드가 오도록 secoffs,user,.. 로 맞춤 (25년 3번).

3. BEAM188 방향 (가장 많이 헷갈림)

  • element x: I → J
  • K 노드가 없으면 element y가 global X-Y 평면에 평행 → 보가 global X 방향이면 element y = global Y, element z = global Z. (보가 global Z와 평행하면 element y = global Y)
  • K 노드(방향 노드)가 있으면 I, J, K가 만드는 평면이 element x-z 평면 → element z가 K 쪽을 향함.
  • 키포인트로 만들 때: latt,MAT,REAL,TYPE,,KB,KE,SECNUM 의 KB 키포인트가 방향점.
원하는 것 방법
I/CHAN 단면(높이=z)을 세워서 수직 하중(−Y)을 강축으로 받기 K 노드를 보 위쪽(+Y)에 두고 e,I,J,K → 하중은 sfbeam, face 1 (element −z)
ASEC / 방향 노드 없이 element y = global Y → 하중은 face 2 (element −y), 강축 I는 Izz에 
! 예: Example 4.5 프레임 (W12×26, K 노드 사용) — '중간고사 풀이.TXT'의 정석 풀이
et,1,beam188,,,3
sectype,1,beam,i
secdata,6.49,6.49,12.22,0.380,0.380,0.230
mp,ex,1,30e6
mp,prxy,1,0.3
n,1,0,108                  ! 9 ft = 108 in
n,2,120,108
n,3,120,0
n,4,0,108+12.06            ! K: 보 1 위쪽
n,5,120+12.06,0            ! K: 기둥 2 오른쪽
e,1,2,4
e,2,3,5
d,1,all
d,3,all
sfbeam,1,1,pres,800/12     ! lb/ft → lb/in

4. SFBEAM (보 분포하중)

sfbeam,Elem,LKEY,PRES,VALI,VALJ,VAL2I,VAL2J,IOFFST,JOFFST,LENRAT

  • Elem: 요소 번호 또는 all(선택된 전체)
  • LKEY(BEAM188): 1 = element −z 방향(I-J 면), 2 = element −y 방향, 3 = 접선(+x), 4 = I 끝, 5 = J 끝
  • VALI, VALJ: I절점, J절점 값. VALJ 생략 → VALI와 같음(등분포). 삼각/선형 분포하중 = VALI≠VALJ
  • IOFFST, JOFFST: 요소 끝에서 하중 시작/끝 위치 오프셋, LENRAT=1이면 비율(0~1). 오프셋은 KEYOPT(3)=3(3차)일 때만 사용 가능. JOFFST=-1이면 IOFFST 위치에 VALI 집중하중
  • 음수 값 = 반대 방향
  • ⚠ 옛 요소 BEAM3는 face 1이 −Y 방향 → 옛 스크립트의 sfbeam,…,1,…(BEAM3)은 BEAM188에서는 보통 face 2(K 노드 없을 때)

삼각 분포하중 처리 (21·23·25년 매번 나옴)

  1. 하중이 꺾이는 점(최댓값), 지점, 결과를 볼 점에 노드가 오도록 선을 나눈다.
  2. 구간마다 선형이므로, 요소 하나하나에 VALI, VALJ를 그 위치의 하중값으로 준다. 요소가 많으면 *do 반복문 사용:
! 가운데(a)에서 최대 wmax, 양 끝(0, L)에서 0인 대칭 삼각하중 : w(x) = wmax*(1-|x-a|/a)
wmax=25000
a=3.75                       ! 꼭짓점 위치 (= L/2)
*get,ne,elem,,count
*do,i,1,ne
  xi=nx(nelem(i,1))          ! 요소 i의 I 노드 x좌표
  xj=nx(nelem(i,2))          ! J 노드 x좌표
  sfbeam,i,1,pres,wmax*(1-abs(xi-a)/a),wmax*(1-abs(xj-a)/a)
*enddo

⚠ APDL에는 <= 같은 참/거짓 비교식이 없다. (A<B)는 둘 중 작은 값, (A>B)는 큰 값을 돌려준다. 꼭짓점이 가운데가 아니면 *if,xi,le,a,then … *else … *endif로 나눈다.
face 번호는 K 노드를 위(+Y)에 둔 경우 1, K 노드 없이 element y = global Y이면 2.

손으로 쓰기 편하려면 노드를 하중 꺾이는 점·지점에만 두고(요소 3~4개), KEYOPT(3)=3(3차)으로 해도 정확도가 충분하다. 결과 비교해 보고 쓸 것.

  • 확인: /psf,pres,,2 + eplot 하중 화살표 표시, sflist
  • 분포하중 단위: lb/ft → lb/in = /12

5. 형상 만들기 (Solid modeling)

명령 문법 메모
키포인트 k,NPT,X,Y,Z 활성 좌표계 기준
선 l,P1,P2,NDIV 활성 좌표계가 원통이면 원호가 됨 → 직선은 csys,0에서
면 a,P1,P2,... / al,L1,L2,... / al,all
사각형 rectng,X1,X2,Y1,Y2 WP 기준, 양 끝 좌표
사각형 blc4,XCORNER,YCORNER,W,H / blc5,XCENTER,YCENTER,W,H 모서리+폭·높이 / 중심+폭·높이
원/도넛/부채꼴 pcirc,RAD1,RAD2,THETA1,THETA2 항상 WP 원점 중심. RAD1·RAD2 순서 무관. pcirc,1 원, pcirc,0.4,1 도넛, pcirc,2.6,3.67,-180,-90 1/4
원 (중심 지정) cyl4,XC,YC,RAD1,THETA1,RAD2,THETA2 인자 순서가 pcirc와 다름
합치기 aadd,NA1,NA2,... / aadd,all 원래 면 삭제, 새 번호
빼기 asba,NA1,NA2,SEPO,KEEP1,KEEP2 NA1에서 NA2를 뺌. 기본은 둘 다 삭제되고 새 면 번호가 생김 → /pnum,area,1 aplot으로 번호 확인. 남기려면 KEEP
겹치기/붙이기 aovlap / aglue glue: 경계 공유(재질 다른 면 연결)
대칭 복사 lsymm,Ncomp,NL1,NL2,NINC / arsym Ncomp=X → x 좌표 부호 반전(YZ면 대칭). 활성 좌표계가 직교(local 직교 포함)여야 함 → 19년 풀이처럼 local,11,0,...로 대칭축을 옮겨서 사용
복사 kgen,ITIME,NP1,NP2,NINC,DX,DY,DZ / lgen / agen ITIME = 원본 포함 총 개수. 원통 csys: kgen은 dR,dθ,dZ / lgen은 dR 무시(dθ,dZ만)

좌표계 / 작업평면

명령 문법 메모
활성 좌표계 csys,KCN 0 직교, 1 원통(R,θ,Z), 2 구, 4 = WP
로컬 좌표계 local,KCN,KCS,XC,YC,ZC,THXY,THYZ,THZX KCN > 10. KCS 0 직교, 1 원통, 2 구. 원점은 global 직교좌표. 만들면 바로 활성화됨
WP 원점 이동 wpave,X1,Y1,Z1,X2,... 활성 좌표계 좌표로 지정(원통 csys면 R,θ). 점 여러 개면 평균 위치
WP 상대 이동 wpoffs,DX,DY,DZ 현재 WP 기준
WP 회전 wprota,THXY,THYZ,THZX
WP 원위치 wpcsys,-1,0 (또는 wpave,0,0,0)
  • 각도는 degree, 하지만 sin()/cos() 함수는 기본 radian (*afun,deg로 바꿀 수 있음).
  • 25년 2번처럼 "삼각함수 금지"면 → NROTAT / NMODIF (§7).

6. 메쉬

esize,SIZE,NDIV     ! esize,0.2 (크기)  /  esize,,1 (선 하나당 1분할: 트러스·보)
lesize,NL1,SIZE,ANGSIZ,NDIV   ! 특정 선만: lesize,1,,,50
type,1 $ mat,1 $ secnum,1      ! 메쉬 전에 속성 지정 (또는 latt / aatt)
lmesh,all           ! 선 → LINK/BEAM
amesh,all           ! 면 → PLANE
mshape,0,2d $ mshkey,1   ! (선택) 사각형 매핑 메쉬
aclear,all / lclear,all  ! 메쉬 지우기

트러스(LINK)는 선 하나 = 요소 하나 (esize,,1). 중간에 노드가 생기면 핀 절점이 생겨 불안정해진다.

7. 노드 / 요소 직접 생성 (Direct generation)

명령 문법 메모
노드 n,NODE,X,Y,Z,THXY,THYZ,THZX 활성 좌표계 기준
노드 채우기 fill,NODE1,NODE2,NFILL 두 노드 사이 등간격 (원통 csys면 원호를 따라)
노드 복사 ngen,ITIME,INC,NODE1,NODE2,NINC,DX,DY,DZ ITIME = 원본 포함 총 개수, INC = 번호 증가. DX,DY,DZ는 활성 좌표계 성분 (원통이면 dR, dθ, dZ)
요소 e,I,J,K,L (en,ID,I,J,...) 현재 type/mat/secnum 적용
요소 복사 egen,ITIME,NINC,IEL1,IEL2,IEINC NINC = 노드 번호 증가량
노드 좌표계 회전 nrotat,NODE1,NODE2,NINC 노드 좌표계를 활성 좌표계 방향으로 회전 (이전 회전 덮어씀). /psymb,ndir,1로 확인
노드 수정 nmodif,NODE,X,Y,Z,THXY,THYZ,THZX 빈칸은 기존 값 유지 → nmodif,5,,,,-60 회전만
요소 속성 수정 emodif,IEL,MAT,2 (TYPE/REAL/SECNUM도)

f, d는 노드 좌표계 기준으로 걸린다 → 노드 좌표계를 돌리면 f,5,fx,..가 기울어진 방향. 결과 출력(prnsol, prrsol)은 기본 global(RSYS,0). 단 *get,..,rf,..는 노드 좌표계 기준.

2025-1 형태: local 원통좌표계 + NGEN + EGEN (PLANE182)

/prep7
et,1,plane182
mp,ex,1,30e6
