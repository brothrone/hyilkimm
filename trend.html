전산구조해석 중간고사 — 족보 경향 분석 & 공부법

자료: 전산구조해석 16·18·21·23·25년 중간.pdf, 중간고사 16·18·19년.txt, 중간고사 대비.TXT, 중간고사 풀이.TXT, 수업 스크립트(9/30~10/21), 강의자료(2026).pdf, BEAM188.pdf 교재: Moaveni, Finite Element Analysis: Theory and Application with ANSYS (수업예제 사진의 Example 4.5 출처)

1. 시험 형식

  • 모든 해 공통 문구: "Write down the ANSYS commands on your answer sheet." → 결과값만이 아니라 명령어 전체를 답안지에 써야 함. 명령어 철자·인자 순서를 손으로 쓸 수 있을 만큼 외워야 한다.
  • 문제 수: 2문제(16·18·21·23년) → 3문제(25년). 문제당 (a)(b)(c)(d) 소문항.
  • 단위는 문제마다 섞여 나온다(in·lb·ft / m·N·GPa / mm·cm). ft→in(×12), cm²→m²(×1e-4), mm⁴→m⁴(×1e-12) 환산 실수가 가장 흔한 감점 포인트.

3. 경향 분석

(1) 매년 나오는 것 — 반드시 손으로 쓸 수 있어야 함

  1. 트러스 / 축부재 (LINK180) — 19·21·23·25년. 거의 매년 1문제. - Example 3.1(발코니 트러스), 3.2(3D 트러스), 계단식/테이퍼 봉이 뼈대. - 출력: 절점 변위(prnsol,u,sum), 요소 축력·축응력(etable,,smisc,1 / etable,,ls,1 → pretab).
  2. 보·프레임 (BEAM188 + 단면) — 16·18·19·21·23·25년. 매년. - 실제 형강 단면(W310×52, C310×45, W8×67, C9×20)을 표에서 찾아 secdata에 넣게 함. - 분포하중은 sfbeam. 최근 3번(21·23·25)은 모두 삼각(선형 변화) 분포하중 → sfbeam,elem,LKEY,pres,VALI,VALJ (VALI≠VALJ). LKEY는 K 노드를 위에 두면 1, K가 없으면 2 — 기출 풀이 세 문제는 모두 face 1.
  3. 스프링으로 바꿔서 "최소 k" 구하기 — 16·18·23년 (3번). LINK로 스프링을 모델링(k = EA/L).
  4. 평형 조건으로 FEA 검증 — 18·23년. 반력 합 = 전체 하중인지 prrfor로 확인.

(2) 변화 방향

  • 옛날 요소 → 최신 요소: 16~19년 원본 풀이는 BEAM188과 함께 옛 요소 LINK1·BEAM3·COMBIN14(실상수 r)를 섞어 썼고, 21년부터 LINK180·BEAM188·PLANE182만 사용. 올해 시험도 최신 요소 기준으로 공부. R(real constant) 대신 SECTYPE/SECDATA 로 단면 입력.
  • 명령어 자체를 지정하는 문제가 늘어남: 25년에 "NGEN·EGEN 사용", "NROTAT·NMODIF 사용", "SECOFFS 사용", "삼각함수 사용 금지"처럼 특정 명령을 쓰라고 함. → 도움말에서 수업 때 짚어준 명령(SECOFFS, SFBEAM, NROTAT/NMODIF, NGEN/EGEN, LOCAL) 이 출제 1순위.
  • 비틀림(torsion) 이 16년 이후 25년에 다시 나옴 (C형강의 전단중심 ≠ 도심 → 하중이 비틀림을 만듦 → SECOFFS가 그래서 나옴).
  • 문제 수가 3문제로 늘고, 형상 만들기(2D 면/메쉬) 문제가 1문제씩 섞임 (18년 Boolean, 19년 lsymm, 25년 NGEN/EGEN).

(3) 올해(2026) 예상

수업 진도(9/30 PLANE42 판 → 10/01·06·07 트러스 → 10/13 BEAM188 → 10/21 프레임+SFBEAM)와 도움말 캡처(BEAM188, LINK180, SECOFFS, SFBEAM)를 보면:

4. 공부법

원칙

  1. 눈으로 보지 말고 손으로 쓴다. 시험은 답안지에 명령어를 쓰는 방식이다. 족보 문제를 빈 종이에 명령어로 처음부터 끝까지 써 본 뒤 ANSYS에 붙여 넣어 돌려서 확인한다.
  2. 한 문제 = 하나의 고정된 틀로 쓴다: /prep7 → 요소·단면·재료 → 형상(k/l 또는 n/e) → 메쉬 → 경계조건·하중 → /solu solve → /post1 출력. (시험 참고자료의 "기본 틀" 참고)
  3. 결과를 손계산으로 검증하는 습관: 반력 합 = 하중, 트러스는 절점 평형, 외팔보는 공식(δ = PL³/3EI, wL⁴/8EI)과 비교.

자주 틀리는 것 체크리스트

  • [ ] 단위 통일 (ft·in, cm²·m², mm⁴·m⁴, lb/ft → lb/in = /12)
  • [ ] 결과를 볼 지점(D, F, y=7.5 in, 하중 꺾이는 점)에 노드가 있는가 → 없으면 키포인트/노드를 그 위치에 추가
  • [ ] 삼각 하중의 꼭짓점·지점 위치에 노드가 있는가 (요소마다 VALI→VALJ 선형)
  • [ ] BEAM188 방향: 하중이 element −y로 가는지 (/eshape,1 + eplot로 단면 방향 확인), 강축 I가 하중을 받는지
  • [ ] 2D 문제를 BEAM188로 풀 때 면외 자유도(UZ, ROTX, ROTY) 구속 또는 d,all로 고정 지점 처리, 롤러는 UY만
  • [ ] LINK180 트러스는 2D라도 UZ 구속이 필요할 수 있음(평면 트러스면 모든 노드 d,all,uz,0)
  • [ ] mp,nuxy(푸아송비, 수업 표기. prxy도 같은 값) 빠뜨림 → BEAM188은 G 계산에 필요
  • [ ] /post1 전에 finish, 결과 읽기 set,last
  • [ ] 스프링 문제에서 k → LINK180 단면적 A = kL/E (E·L은 아무 값이나 정해도 됨)

스프링 "최소 k" 빠르게 푸는 법 (중첩법, 선형이므로 정확)

  1. 스프링 없이 하중만 → 관심점 변위 δ₀
  2. 하중 없이 관심점(스프링 붙는 점)에 단위하중 1 → 관심점 변위 f (유연도) - 관심점과 스프링 위치가 다르면 f_ss(스프링 점), f_ps(관심점) 두 값을 읽는다
  3. 스프링 힘 R = k·δ_s, δ_s = δ₀ₛ/(1 + k·f_ss) → 관심점 변위 δ_p = δ₀ₚ − f_ps·k·δ₀ₛ/(1 + k·f_ss)
  4. δ_p = 허용값으로 놓고 k를 풀고, LINK180 단면적 A = k·L/E 를 넣어 다시 돌려 확인. (시행착오로 k를 바꿔 가며 돌려도 되지만 시간이 오래 걸림)

비틀림 0으로 만드는 반대 모멘트 (25-3(b))

선형 해석이므로: 하중만 → 비틀림각 θ₀, 단위 모멘트 1만 → θ₁ ⇒ M = −θ₀/θ₁. 다시 돌려서 θ ≈ 0 확인.
